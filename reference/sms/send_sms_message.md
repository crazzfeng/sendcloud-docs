# Send SMS

Send SMS templates to one or more recipients using this endpoint.

## Overview

This endpoint allows you to send personalized SMS messages to multiple recipients simultaneously. You can use predefined templates with dynamic content insertion to create targeted messaging campaigns.

## Key Features

- **Template Support**: Use customizable SMS templates with variable placeholders
- **Bulk Messaging**: Send messages to multiple recipients in a single API call
- **Personalization**: Insert recipient-specific data into message templates
- **Delivery Tracking**: Monitor message delivery status and performance

## Use Cases

- **Marketing Campaigns**: Send promotional messages to customer segments
- **Notifications**: Deliver important updates, alerts, or reminders
- **Authentication**: Send verification codes and security notifications
- **Customer Support**: Provide automated responses and support updates

## Getting Started

To send your first SMS message, you'll need to:

1. Prepare your message template with any necessary variables
2. Compile your recipient list with their phone numbers
3. Make a POST request to this endpoint with your template and recipient data
4. Monitor the response for delivery confirmation and tracking information
