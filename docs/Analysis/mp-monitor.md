# What is MP Monitor

<Image align="center" alt="MP Monitor" border={false} caption="MP Monitor" src="https://files.readme.io/948724cd1ce55938b3c30b5a32b4c7bed148989df824373dd8209ad2db3f6bae-image.png" />

MP Monitor (Mailbox Provider Monitor) is a dedicated monitoring feature for feedback data from Mailbox Providers . Within this feature section, you can view information related to Feedback Loops and other Complaint Reporting. After completing the configuration, you can also obtain reputation scores generated by MPs for your Domain and IP address, as well as the number of spam complaints counted in MP feedback.

* Provides direct support for email delivery optimization, serving as a practical feature section to improve email sending performance.
* Outputs valuable data analysis results, offering data basis for optimizing email performance  (such as delivery and inbox placement performance).
* Helps improve email delivery rate and inbox placement rate, reducing the chance of emails being marked as spam or blocked.
