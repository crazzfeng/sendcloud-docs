Your First Email



We have created the test sending domain and API_USER for every account. And you can test the sending directly. There are two way to send your first email:"Send by template" or "Send by code".

# Create & Verify Sending Domain

The sending domain serves as the "ID" of an email.

<br />

# Create API_USER

You will use API_USER to send emails.

 

# Start Sending

This is the final step to start sending emails. Click "Use API" to start sending emails via API. Or click "Create Campaign" to create an email campaign for sending.
