# Newbie Guide

This section guides you through the process of setting up and starting to send emails.

. Your First Email
Description: The sending resource is ready, and you can test it.
Action: Click the "Quick Testing" button to perform a quick test of sending an email.
1.2 Create & Verify Sending Domain
Description: The sending domain serves as the "ID" of an email.
Action: Click the "Create Domain" button to create and verify your sending domain.
1.3 Create API_USER
Description: You will use API_USER to send emails.
Action: Click the "Create API_USER" button to create an API_USER for email sending.
1.4 Start Sending
Description: This is the final step to start sending emails.
Actions:
Click "Use API" to start sending emails via API.
Click "Create Campaign" to create an email campaign for sending.
