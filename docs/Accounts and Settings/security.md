<br />

We provide four security verification methods:

Login password
Registered email
Binding mobile phone
Google authentication
When modifying security settings, the default authentication mode of the system is as follows:

When mobile phone number and Google authentication are not bound, login password and email verification code are used for authentication.
When the mobile phone is bound but not Google authentication, the login password and mobile phone verification code are used for authentication.
When Google authentication is bound, the login password and Google verification code are used for authentication.
2FA Login

After the switch is turned on, the second authentication is carried out according to the setting mode when logging in to protect the security of your account.

Setting of pixelating sensitive information

When switch is on, the sensitive information will be pixelated

Exportation verification

After the switch is turned on, the delivery response data will be exported and verified according to the setting mode.
